A few useful details

Before you share.

Do recipients need Quire?

No. They need a browser, the complete share link, and the password if you set one. Shared pages are read-only.

Can I host Quire on GitHub Pages?

This project website runs on GitHub Pages. Quire itself needs its application server and Postgres database to publish, store, and serve shared conversations. Follow the self-hosting guide.

What happens to secrets in a conversation?

The server redacts recognized secrets during ingestion, before persisting transcript content. Review what you share: rules cannot catch every sensitive detail, and text redaction does not inspect image pixels. The ingestion server sees the original upload, so this is not end-to-end encryption against the server.

Can I take a shared conversation down?

Yes. Revoke the link using the CLI, or set an expiration. This stops future access through your server; it cannot erase screenshots or copies someone has already saved.

Which coding tools are supported?

Claude Code, Codex, ZCode, and Oh My Pi. Claude Code and ZCode use /share; Codex uses $share. Oh My Pi uses /share after installing its Quire handler. See the integration guide for setup and per-tool behavior.
